# Gate 6B — Fixed-point target x stop study

This DEVELOPMENT-only study covers 15m/20m/30m PRINT across five fixed targets
(40/50/60/75/100 points) and five stop definitions (OR midpoint, 25% OR
retracement, and fixed 30/40/50-point stops): exactly 75 configurations.

The validated signal, PRINT entry, entry-bar ambiguity, session-end, and daily
trade-limit layers remain authoritative. Fixed targets are independent of risk;
trade results remain expressed as realized PnL divided by initial risk.

The OR-width diagnostic CSV retains every eligible candidate with OR width,
target/OR ratio, stop/OR ratio, initial risk, initial reward/risk, outcome, and
inclusion/rejection fields for Gate 6B.1. These values are diagnostic only; no
OR-width filter or threshold is applied in Gate 6B.

Metadata contains before/after SHA-256 hashes proving Gate 6A and Gate 6A.1
artifacts were unchanged. The seven HTML response surfaces are descriptive and
do not rank or select a configuration.
